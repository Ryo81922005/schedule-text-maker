# 日程テキストメーカー

期間と「曜日 × 時間帯」の週間テンプレートから、日程調整サービスへ貼り付ける候補日テキストを作成するWebアプリです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 開始日と終了日を選びます。
3. 表の中にある「時間帯を追加する」を押し、最初の時間帯を作ります。
4. 時間帯を入力し、対象の曜日を選びます。
5. 必要なら表上部の「時間帯を追加」で行を増やします。各行の「↑」「↓」で後から並べ替えられます。
6. 「日程テキストを生成」を押します。
7. コピーしたい日程にチェックを付けます。生成直後はすべて選択されています。
8. 「選択した日程をコピー」で、チェックした日程だけをコピーします。

出力例：

```text
8/3(月) 10:00~12:00
8/3(月) 18:00~20:00
8/5(水) 10:00~12:00
```

## テンプレート

テンプレート名を入力して「保存」を押すと、現在の曜日と時間帯の設定をブラウザ内に保存できます。同名で保存しようとした場合は確認画面が表示され、「上書きする」を選んだときだけ更新されます。

保存先はブラウザの `localStorage` です。サーバーには送信されませんが、別のブラウザや端末とは共有されません。

## ファイル構成

- `index.html`：画面の構造
- `style.css`：配色、レイアウト、スマートフォン対応
- `script.js`：画面操作、コピー、テンプレート保存
- `schedule-core.js`：日付の検証と候補日生成
- `tests/schedule-core.test.js`：日程生成ロジックのテスト

## ローカルサーバーで起動する場合

このフォルダで次のコマンドを実行し、`http://127.0.0.1:8000/` を開きます。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

## テスト

Node.jsが使える場合は、次のコマンドで日程生成ロジックを確認できます。

```powershell
node tests/schedule-core.test.js
```
